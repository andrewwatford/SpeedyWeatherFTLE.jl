Plotting

The plotting helpers are optional. They load through a package extension after GeoMakie is available, so compute-only users can load SpeedyWeatherFTLE without loading Makie.

using CairoMakie
using GeoMakie
using RingGrids
using SpeedyWeather
using SpeedyWeatherFTLE

CairoMakie.activate!()

spectral_grid = SpectralGrid(nlayers = 1, trunc = 8, Grid = FullGaussianGrid)
values = zeros(spectral_grid.npoints, 3)
values[:, 1] .= NaN
values[:, 2] .= range(0.0, 0.20; length = spectral_grid.npoints)
values[:, 3] .= range(0.05, 0.30; length = spectral_grid.npoints)

ftle = Field(values, spectral_grid.grid)
time_hours = [0.0, 6.0, 12.0]

In normal use, ftle and time_hours come from FTLE. The synthetic field above keeps the plotting examples small and reproducible.

Surface Plot

surface_plot accepts a RingGrids.Field directly. For a time series field, it uses the final selected column by default and labels the colorbar as FTLE [1/h].

fig, ax, sp, cb = surface_plot(
    ftle;
    time_hours,
    coastlines = false,
    title = "Forward FTLE",
)

Select a saved integration horizon by index or by nearest hour:

surface_plot(ftle; time_hours, time_index = 3, coastlines = false);
surface_plot(ftle; time_hours, time_hour = 12, coastlines = false);

Use shared_colorrange for comparable plots:

shared = shared_colorrange(ftle; pad = 0.05)
surface_plot(ftle; time_hours, colorrange = shared, coastlines = false);

Slider Plot

slider_plot shows each saved nonzero integration horizon. It skips zero-duration FTLE columns by default because FTLE is undefined at release.

handle = slider_plot(
    time_hours,
    ftle;
    return_handle = true,
    coastlines = false,
)

set_slider_time!(handle, 12)

The returned SliderPlotHandle exposes the figure, axis, surface, colorbar, slider, live label, and plotted times.

Record an animation with the same controls:

animate_slider_plot(
    "ftle.gif",
    time_hours,
    ftle;
    framerate = 6,
    coastlines = false,
)
"ftle.gif"

Globe Plot

globe_plot uses GeoMakie's GlobeAxis. With GLMakie active, the globe can be rotated interactively. With CairoMakie, it renders as a static figure.

fig, ax, sp, cb = globe_plot(
    ftle;
    time_hours,
    time_hour = 12,
    coastlines = false,
    colorbar = true,
)
